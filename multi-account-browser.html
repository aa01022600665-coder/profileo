Multi-account management

Multi-Account Browser for Separate Workspaces

A multi-account browser gives each workspace its own browser session. Profileo combines separate profile data with configurable fingerprints and per-profile proxy settings.

Give each account a clear workspace

When you switch between client accounts in a single browser, it is easy to use the wrong session or change the wrong settings. A named browser profile gives you a repeatable place to return to each account, with its own cookies and browsing data.

For example, an agency can use profiles named “Client A — reporting” and “Client B — reporting”. A store operator can separate an approved production account from a testing workspace. Only create accounts and sessions you are authorized to manage.

A practical setup in Profileo

  1. Choose New Profile and give the workspace a name that identifies its owner and purpose.
  2. Choose the browser and review the profile settings. Keep the configuration consistent with the work you need to perform.
  3. Assign a proxy when the workspace requires a separate network route. A browser profile alone does not change your public IP address.
  4. Launch the profile, verify the network and sign in to the intended account.
  5. Add tags and notes so you can find the workspace again. Stop the browser when the session is finished.

The browser-profile guide covers the controls in detail. For proxy setup, use the proxy configuration guide.

Five habits for managing e-commerce accounts

  1. Follow the marketplace rules for account ownership and permitted additional accounts. Browser software does not grant permission for extra accounts.
  2. Use one clearly named workspace for each approved store or role. Check the active profile before changing listings or orders.
  3. Keep account recovery and two-factor authentication under the control of the authorized owner.
  4. Test the proxy and browser settings before handling a live session; avoid changing them unnecessarily during work.
  5. Document the purpose of each profile and remove access when a collaborator no longer needs it.
