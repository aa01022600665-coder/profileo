How it works

From one successful test to a repeatable workflow

Multi-browser automation applies a saved sequence of actions to selected browser profiles. Each profile keeps its own account context; the script supplies the repeatable steps.

01 / PREPARE

Choose the account context

Create clearly named profiles and confirm their sessions and proxy settings. Start with a test profile so you can see exactly what the workflow changes.

Set up browser profiles →
02 / BUILD

Connect the actions

Use Create Script to arrange supported browser actions on the canvas, or review an existing script. Set the URL, selectors and other inputs before saving.

Follow the visual builder guide →
03 / RUN

Select profiles and review results

Run the script on one profile first. Once the result is correct, select more profiles and monitor their status. Stop a run when the browser reaches an unexpected state.

Run across selected profiles →
Built into Profileo

A visual builder for browser tasks

Combine navigation, waiting, clicks, text entry and scrolling without writing a complete script. Use parameters to change inputs between runs while keeping the workflow reusable.

For advanced steps, the builder includes a JavaScript Code action that runs in the page. The built-in engine uses Puppeteer to drive the browser.

Questions, answered

Before you automate multiple browser profiles

Do I need to code to use browser automation?

You can build supported workflows with visual action blocks and configure existing scripts without writing code. Selecting page elements may require a CSS selector. More advanced page logic can use the JavaScript Code block.

Can I run the same script on multiple profiles?

Yes. The run dialog lets you select multiple profiles. Test one profile first, then expand gradually. Practical capacity depends on your computer, the workflow and your plan; this page does not promise a fixed number of simultaneous browsers.

Is browser automation the same as synchronizing windows?

A saved automation workflow executes defined steps on selected profiles. Window synchronization mirrors live input between windows. This page describes the script-based automation workflow in Profileo.

How do I know whether a run worked?

Review the status panel and the actual page result. Some missing-element or timeout errors can be skipped by the engine, so a completed status alone does not validate the outcome. The troubleshooting guide explains what to check.

Which version does the guide cover?

The controls described here are based on the public Profileo 1.3.8 release for Windows. Review current plans for availability and limits, and use the official download page to get the public installer.
