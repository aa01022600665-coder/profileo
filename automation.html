Custom Puppeteer Scripts

Write your own automation scripts using Puppeteer. Full access to the browser API for unlimited customization and advanced workflows.

  • Full Puppeteer API access
  • Access to profile cookies and storage
  • Import community scripts
custom-script.js 
const browser = await profileo.launch(profileId);
const page = await browser.newPage();

// Navigate to target
await page.goto('https://youtube.com');
await page.waitForSelector('#search');

// Type search query
await page.type('#search', params.keyword);
await page.click('button#search-icon');

// Watch and interact
await page.waitForTimeout(params.duration);
await page.click('#like-button');
